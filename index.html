Test Form Generator (Word .docx)

Format help

One question per line. Bullets (*) under a question are the answer choices. The first bullet is always the correct answer; each form scrambles the order.

A question containing ___ (three underscores) is fill in the blank. Bullets under it are the answers for each blank, in order (the key shows them).

Sections stay in order, one page each. Questions and choices scramble inside a section. Use **bold** and `code`. Lines starting with // are ignored.

Privacy: this page starts blank and sends nothing anywhere. Load JSON stores the test bank only in this browser (local storage) so it can be edited and debugged locally. Keep the JSON file out of the public repository.

Images: click + Images in a section, then paste a tag such as [[img1]] (click the tag under a picture to copy it) into a question line or into a bullet to make a picture answer choice.
